Resources to study Deep Learning

Here are some free resources which will help you to study deep learning.

Pre requisite : Basic Linear Algebra, Basic Python

NOTE : MUST WATCH THESE VIDEOS IN SEQUENCE

  2. PyTorch ( Lecture 1 to 17, remaining lectures do later.) https://youtube.com/playlist?list=PLqnslRFeH2UrcDBWF5mfPGpqQDSta6VK4&feature=shared
  3. DL theory : Andrew NG https://youtube.com/playlist?list=PLkDaE6sCZn6Gl29AoE31iwdVwSG-KnDzF&feature=shared
  4. DL practical : Fast.ai Fundamental : https://youtube.com/playlist?list=PLfYUBJiXbdtSvpQjSnJJ_PmDQB_VyT5iU&feature=shared Advance : (do it or not, up to you) https://youtube.com/playlist?list=PLfYUBJiXbdtRUvTUYpLdfHHp9a58nWVXP&feature=shared
